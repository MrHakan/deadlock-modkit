# v0.3.0 · Buy now, lane counters, patch warnings, profiles, and automatic updates

Experimental HUD for Deadlock client build **6864**.

### HUD

- **What to buy now.** A **BUY NOW** badge marks the first suggestion your souls can pay for, and prices you cannot reach yet turn grey. Souls come from your top-bar card.
- **Owned items are left out.** Items you already bought this match no longer take a suggestion slot, so the list always shows something new.
- **Lane counters.** For the first ten minutes the fourth row shows the best early item (at most 3,200 souls) against the enemies in your lane. The game marks those players itself, and the match clock decides when laning ends.
- **Patch warnings.** When a patch changes an enemy hero after the counter table was last reviewed, a **PATCHED** badge appears next to the title; when it changes a suggested item, that row gets a **!** mark. Hover either one to see what changed, taken from Valve's patch notes. The warnings stay until the counters are reviewed for that patch. This release flags the 11-04-2026 changes to Apollo, Baba, Celeste, Deadman Danny, Mo & Krill, Nurse Harrow and Healbane. Only these marks react to the mouse; the rest of the panel lets clicks through.
- **Changes without patch notes are caught too.** The data tool compares the hero, ability, weapon and item values of the build the counters were reviewed on with those of the current build. A change no patch note mentions gets the same warning, listed as *an update without patch notes*. It already found one: build 6833 raised Spiritual Overflow's spirit lifesteal from 13% to 15% without notes. The same comparison confirms that the 11-04-2026 notes list every hero whose values changed.
- **Typical buy minute.** Each row shows when the item is usually bought, next to its measured win-rate change, for example `+0.6 WR · ~14m`.
- **Pocket and Rat King** now have reference counters, picked from Deadlock Item Builder's counter guides and checked against match data. All five Rat King picks raise the buyer's win rate. For Pocket, three picks the data contradicted were replaced.
- **Match data starts at the latest gameplay patch.** The data tool reads the patch notes and starts the window at the newest update that changed an item or a hero (currently 11-04-2026). The previous 30-day window mixed in data from before the 10-30 update, which changed 12 of the counter items.

### The 11-18-2026 game update

Builds 6863 and 6864 changed no hero, ability, weapon or item value and no interface file, so the counters, the match data and this HUD stay valid, and no new warnings are needed. The download was large because the update rebuilt about 4,600 hero animation files and replaced Baba's ability effects (77 effect files removed, 35 changed). It also replaced `gameinfo.gi`, which turns every mod off: press `r` in dlmod, or add the search paths to the new file again.

### dlmod

- **Profiles.** Save the mods that are on as a named set and switch between sets (`f` in the full-screen view, or `dlmod profile save|use|delete`).
- **`dlmod update`** (`u` in the full-screen view) downloads the HUD built for your installed game build from this project's releases, checks GitHub's published SHA-256, and replaces the old version in its slot. It is the only command that goes online, and it uses the `curl` that comes with Windows 10 and later, so dlmod stays at about 3 MB instead of doubling.
- `x` now undoes the `gameinfo.gi` change; `u` is the update.

### Automatic releases after game updates

A daily workflow checks Deadlock's client build. When it changes, it refreshes the catalog, the match data and the patch warnings, runs every test, builds the mod against the new stock HUD, and publishes the next patch release. An interface mod built for an older build can stop the game from starting, and this keeps a matching HUD available, usually within a day.

### Install

Close Deadlock first.

- **With dlmod:** download the ZIP and `dlmod-windows-amd64.exe`, drag the ZIP onto the exe, and start Deadlock. Later, press `u` in dlmod to update the HUD, and `r` after a game update.
- **By hand:** add the `citadel/addons` search paths to `game/citadel/gameinfo.gi` and copy `pak01_dir.vpk` into `game/citadel/addons`. The README lists the exact lines.
- **With Deadlock Mod Manager v2.3.0:** select **Mods Library → Add Local Mod**, import the ZIP, enable the mod, and launch through Mod Manager.

All local tests passed (15 JavaScript, 9 Python, 21 Go), and the shipped script was run against the new data in a mock Panorama. The panels behind the new HUD features come from Valve's interface files. If one turns out to be named differently in game, that feature switches itself off: no badge without souls, no lane row without lane opponents. Hover tooltips use Panorama's standard mouse events. Displaying the HUD in Deadlock and running dlmod on Windows have yet to be verified.
