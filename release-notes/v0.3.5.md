# v0.3.5 · Owned items fixed, the + QUEUE button removed, and dlmod browses mods online and replaces sounds

Experimental HUD for Deadlock client build **6864**.

- **Removed the + QUEUE button added in v0.3.4.** Clicking it queued nothing, and it could freeze the player: WASD and the shop key stopped working until an ability was cast. The game's quick-buy event (`CitadelQuickbuyAddItem`) is undocumented, and the button called it with guessed arguments. The button also accepted keyboard focus, while Valve's own HUD buttons set `acceptsfocus="false"`. It stays out until the event's real arguments are known.
- **Items you own are no longer suggested (#10).** The mod looked for item names in properties of the item icons, which the game does not expose, so an item you owned could still be suggested with BUY NOW. With the shop open, it now reads the shop's own item cards: the ones the game marks as owned, or as part of an upgrade you own, drop out of the suggestions for the rest of the match. The item icons are also asked for their `{s:mod_name}` dialog variable, which the shop cards use. If the icons answer it, the scoreboard's *Countering you* line works as well.
- **The PATCHED badge and the ! marks no longer take keyboard focus.** They are the only parts of the panel that react to the mouse, and they now use `acceptsfocus="false"` as well. A test checks that every panel the mouse can reach does.

### dlmod: browse and install mods online

- **`b` opens the online catalog** that Deadlock Mod Manager uses: about 12,000 mods mirrored from GameBanana by deadlockmods.app, each with its hero and category. You can pick a hero with `←` `→`, cycle categories with `c`, search with `/`, and install the selected mod with `Enter`. Downloads are checked against their published MD5. The list is cached for six hours.
- **Previews in the terminal.** The selected mod's picture is drawn as coloured blocks in any modern terminal, or at full resolution with sixel (Windows Terminal 1.22+, WezTerm, foot) or the kitty protocol. Sixel pictures get a palette made for each picture, with dithering, at the pane's exact pixel size. dlmod asks the terminal whether it draws sixel, so Windows Terminal 1.22+ gets full resolution without any setting. `v` shows a big preview that fills the screen, `m` switches modes, and `DLMOD_IMAGES` sets the starting one. dlmod draws these itself with Go's standard library.
- **`.rar` and `.7z` mods install** through the `tar.exe` that comes with Windows, or 7-Zip. About 40% of skins on GameBanana are RAR archives.
- **Replace any game sound** (`s`): pick a hero's voice line or ability sound, listen to it, and drop a `.wav` or `.mp3` on the window. dlmod compiles it into the game's sound format itself (no Valve tools, Blender or Source 2 Viewer) and installs every replacement as one mod, *Custom sounds*. Compiling the MP3 inside one of Valve's own sounds reproduces every field Valve's compiler wrote.
- **`dlmod search <words> -hero <hero>` and `dlmod get <id or GameBanana address>`** do the same from the command line.

Everything else is as in v0.3.4: item icons, hero portraits, the "Countering you" line on the scoreboard, and the shop's quick-buy list in its stock place.

Close Deadlock first, then press `u` in dlmod to update the HUD.

All 19 JavaScript, 9 Python and 32 Go tests passed, and the mod was built against the live build-6864 stock HUD.
