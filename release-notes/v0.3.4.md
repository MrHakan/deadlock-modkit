# v0.3.4 · Portraits, counters against you on the scoreboard, quick buy, and the shop's buy list back in place

Experimental HUD for Deadlock client build **6864**.

### Fixes

- **The shop's quick-buy list is back under the Quick Buy button.** Since v0.3.0 the mod moved it 540 pixels to the right, over the shop's navigation tabs. The mod's class listener sat directly under the stock HUD panel and gave it a second `gShopOpen` class, which matched one of Valve's own style rules and moved the list. The listener now has a panel of its own, so its classes never reach the game's panels. The same fix keeps the scoreboard class off them too.

### New

- **Hero portraits.** Each suggestion shows the portraits of the heroes it answers instead of their names. The portraits come from the game's own textures, so all 44 heroes are covered.
- **Counters against you, on the scoreboard.** When you hold Tab, the mod reads the items each enemy owns from their card. Items from your own hero's counter list appear in red under the panel title, for example *Countering you: Healbane (Haze)*, and raise the purchase banner once.
- **+ QUEUE.** Each row has a button that adds the item to the game's quick-buy queue. It uses the game client's `CitadelQuickbuyAddItem` event, whose argument is not documented. The mod tries the item ID first, and the console shows `[DCI] Quick buy: queued …` with the form the game took. If the Quick Buy count does not go up, please report that console line.

Close Deadlock first, then press `u` in dlmod to update the HUD.

All 18 JavaScript, 9 Python and 21 Go tests passed, and the mod was built against the live build-6864 stock HUD. The quick-buy list fix follows from Valve's style rule and from screenshots with and without the mod. Portraits, the scoreboard warning and the queue button have not yet been seen in Deadlock.
