# v0.4.1 · Better rigging for wide clothes, new README screenshots

Experimental HUD for Deadlock client build **6864** (unchanged).

- **Model studio: wide trousers and coats no longer lift with the arms.** When the hero's arms were lowered to match a model, a lowered elbow sat beside the hips. An arm now claims vertices only near the shoulder; elbows and hands are labelled by walking across the arm's surface.
- **README:** new screenshots from dlmod 0.4.0: the mod list, the online browser and big preview in sixel, the sounds screen, and the model studio with its rig check.

Everything else is as in v0.4.0. All Go, JavaScript and Python tests passed.
