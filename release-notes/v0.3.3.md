# v0.3.3 · Item icons

Experimental HUD for Deadlock client build **6864**.

- **Each suggestion shows its item icon.** The icon comes from the game's own files (for example `panorama/images/items/vitality/healbane_psd.vtex`), so the HUD still makes no network requests during a match. It is drawn the same way as the category glyphs it replaces, framed in the item category's colour. All 173 shop items have an icon in build 6864.
- `tools/update_catalog.py` records the icon of each item, taken from deadlock-api's shop image, so future catalogs keep them.

Close Deadlock first, then press `u` in dlmod to update the HUD.

All 17 JavaScript, 9 Python and 21 Go tests passed, and the mod was built against the live build-6864 stock HUD. The icons have not yet been seen in Deadlock.
