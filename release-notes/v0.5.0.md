# v0.5.0 · Custom characters: a whole hero of your own, with Meshy prompts for every hero

Experimental HUD for Deadlock client build **6864** (unchanged), and dlmod grows from a model importer into a kit for whole replacement characters. The README is new: a short tour of the three tools, with the details in [docs/](https://github.com/MrHakan/deadlock-modkit/tree/main/docs).

### dlmod: a whole replacement character

- **A Meshy workspace for every hero.** [`meshy/`](https://github.com/MrHakan/deadlock-modkit/tree/main/meshy) has a folder for each of the 44 heroes with [Meshy](https://www.meshy.ai) prompts written for that hero's role, weapon and four abilities: a design sheet, front, side and back views, the 3D model, hero select art, cards and portraits at the game's sizes, one icon per ability, and the ability models. Each step names the Meshy tool, model, aspect ratio and cost (about 150 credits for a whole hero) and the game file it replaces. `dlmod meshy <hero> meshy concept="…"` fills your character's description into them.
- **`dlmod apply meshy/<hero>`** installs everything generated so far in one go: the model, the hero select screen, the cards (a flat green background is keyed out), the icons and the ability models.
- **Hero select screen: `dlmod select`.** The background picture, the big name logo (drawn with a built-in stroke font, or your own SVG), the three tags and their colours. `scene=hide` empties the hero's 3D scene so your picture shows on its own.
- **Ability icons: `dlmod icons`.** Pictures drawn white on black become the white glyphs the HUD tints.
- **More commands:** `dlmod image` (cards and portraits), `dlmod prop` (thrown and placed ability models, including the older model layout), `dlmod paint` and `dlmod effects` (recolour ability effects, and with `paint` their textures and materials, to a palette), `dlmod text` (any line of hero text).

### dlmod: models

- **The hero studio** gains Sounds, Images, Text and Effects tabs, and advanced rig tools: pose preview, weight painting, pinned pieces and a joint map. `m` in the full-screen view opens it.
- **Meshy rigs map by skeleton shape.** Joints named `Bone_000…` are read as chest, hips, arms and legs from how the skeleton forks, instead of by nearness.
- **Models rigged on the hero's own bones are kept as they are**, a new custom model replaces the hero's previous one, and vertices on `root_motion` stand upright in game.
- **`-keep none` and `-move muzzle_flash=X,Y,Z`** drop the hero's gun and move where shots start, for a character that holds something else.
- **Faster rigging:** a 127,000-vertex model rigs in 2 s instead of 47 s.
- **Fixes:** the game's own hero models import correctly (attribute names, levels of detail, bones past 255); a rejected archive is closed; a mod installed while another dlmod window or command was running is no longer dropped from the list.

### What we learned about Deadlock

Making a character that looks nothing like its hero showed how the game treats heroes: any model plays the hero's own clips; melee and reloads move only the upper body, through bone masks, while IK pulls both arms to the gun; the hero select screen is a small 3D map per hero with an SVG name logo; and some bones are special. The [custom characters guide](https://github.com/MrHakan/deadlock-modkit/blob/main/docs/custom-characters.md#what-we-found-out-about-deadlock) has the details.

Everything else is as in v0.4.1. All Go tests passed locally; the release workflow runs the Go, JavaScript and Python tests before publishing.
