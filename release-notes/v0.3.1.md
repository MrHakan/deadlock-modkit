# v0.3.1 · Suggestions show up in game, and the panel moves out of the way

Experimental HUD for Deadlock client build **6864**. Fixes [#3](https://github.com/MrHakan/deadlock-counter-intelligence/issues/3) and [#4](https://github.com/MrHakan/deadlock-counter-intelligence/issues/4) as far as tests outside the game can tell; please confirm in a match.

### Fixes

- **The panel recommended nothing (#4).** In v0.3.0 the panel never left its layout defaults: "Waiting for enemy lineup.", a PATCHED badge and empty rows with **!** and BUY NOW marks. The script looked for the shop and scoreboard classes on the wrong panel (the game puts them on the listener's parent), so it stopped before drawing anything. It now reads them where the game puts them.
- **Empty rows and badges are hidden.** They are now hidden with a CSS class, because the layout's `visible="false"` had no effect in game.
- **The panel no longer covers stock panels (#3).** In the shop it sits on the left under Quick Buy instead of over your souls and items. On the scoreboard it sits above the ability bar instead of over the incoming-damage panel.
- **Souls are your spendable balance.** BUY NOW now follows the souls you can spend (the shop or HUD balance) instead of the top bar's net worth.
- **Hero and team detection are sturdier.** Teams are told apart by the local player's card, and a hero whose ID cannot be resolved is matched by its displayed name.
- When the script loads, it writes `[DCI] Counter items HUD loaded` to the console. If that line is missing, the script did not load.

### Install

Close Deadlock first. With dlmod, press `u` to update the HUD, or drag the new ZIP onto `dlmod-windows-amd64.exe`. If the 11-18 game update turned mods off, press `r`. The README describes installing by hand or with Deadlock Mod Manager.

All 17 JavaScript, 9 Python and 21 Go tests passed, and the mod was built against the live build-6864 stock HUD. The new panel positions have not yet been checked in Deadlock.
