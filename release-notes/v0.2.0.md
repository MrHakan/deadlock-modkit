# v0.2.0 · Reference counters, match data, and enemy purchase alerts

Experimental HUD for Deadlock client build **6864**.

- **Reference counters.** Suggestions come from a table of five counter items for each of 42 heroes, taken from the *Counter Eşyalar: kime karşı ne alınır?* series. The scoreboard and shop show the three items that counter the most enemy heroes, with soul price, item category, a short tag for what the item does (for example *Anti-heal* or *CC immunity*), and the enemy heroes it counters.
- **Match data.** Each row shows the estimated change in the buyer's win rate against the current lineup, measured from deadlock-api matches between October 20 and November 19. The values are corrected for buyer bias, hero strength, and item timing. A fourth row adds the item with the largest measured gain against the lineup. Pocket and Rat King, who are not in the reference series, are covered by match data.
- **Enemy counter-purchase alerts.** When an enemy buys an item from the counter list of a hero on your team, a banner names the buyer, the item, and the allies it counters for 8 seconds. It turns red when the item counters your hero. Each purchase alerts once per match. Enemy purchases are read from the shop's recent-purchase list, so alerts appear when you open the shop.
- **dlmod, an installer that needs no mod manager.** `dlmod-windows-amd64.exe` (3 MB, no installer, no network access) finds Deadlock through Steam, copies mods into `game/citadel/addons` under free `pakNN_dir.vpk` names, and edits `gameinfo.gi` so the game loads them. It works with any VPK mod. Double-clicking opens a full-screen view: arrow keys select, Space switches a mod on or off, dragging a file into the window installs it, and conflicts, update warnings and the game's mod state show at a glance and update by themselves. It repairs `gameinfo.gi` after game updates and restores Valve's file exactly when you undo it. It uses about 5–8 MB of memory and responds to key presses in under a millisecond.
- Weapon items now show the weapon category icon.

`docs/counter-data.md` compares the reference table with match data for every hero: 70 of the 210 reference picks raise the buyer's win rate measurably, 65 show no significant change, and 75 lower it.

### Install

Close Deadlock first.

- **With dlmod:** download the ZIP and `dlmod-windows-amd64.exe`, drag the ZIP onto the exe, and start Deadlock. After a game update, double-click dlmod and press `r` to repair. Windows SmartScreen may warn about the unsigned program: choose **More info → Run anyway**.
- **By hand:** add the `citadel/addons` search paths to `game/citadel/gameinfo.gi` and copy `pak01_dir.vpk` into `game/citadel/addons`. The README lists the exact lines.
- **With Deadlock Mod Manager v2.3.0:** select **Mods Library → Add Local Mod**, import the ZIP, enable the mod, and launch through Mod Manager.

All local tests passed (11 JavaScript, 5 Python, 16 Go), and the VPK archive was verified. dlmod was run end to end on Linux against a copy of the build 6864 `gameinfo.gi`, including its full-screen view in a terminal. The Windows build is cross-compiled and has not been run on Windows yet; if its full-screen view misbehaves, `dlmod -plain` opens the numbered menu. Loading the mod in Deadlock and displaying the HUD and alerts still have to be verified in game.
